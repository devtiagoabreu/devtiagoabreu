### 🧭 Sobre mim

Sou desenvolvedor Full-Stack, atualmente na **Atriostech**, onde crio soluções em JavaScript, TypeScript, PHP e C# para **integrar sistemas** e **gerar dashboards para tomada de decisão**. Gosto de resolver problemas reais de negócio com código — desde integradores de ERP até sistemas de gestão e páginas institucionais.

- 🔭 Trabalhando atualmente em integrações e automações corporativas
- 🌱 Sempre estudando novas formas de conectar dados entre sistemas
- 📍 Santa Bárbara d'Oeste, SP — Brasil
- 💬 Me chame para falar sobre JS/TS, PHP, C# ou integrações de sistemas
